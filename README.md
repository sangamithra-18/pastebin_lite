Pastebin Lite – Full Stack Exercise
Project Overview

Pastebin Lite is a simple full-stack web application that allows users to create, view, and share text snippets (pastes). The application demonstrates core full-stack development concepts, including frontend rendering, backend APIs, and cloud database integration.

Live Demo

🔗 Application URL:
https://pastebin-lite-iph6.onrender.com

Features

Create a new paste with text content

View saved pastes

Simple and clean user interface

Connected to PostgreSQL (Neon) database

Deployed and accessible via public URL
